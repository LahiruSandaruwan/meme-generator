### Icon Design Guidelines

**Do's:**
- Use simple, recognizable imagery
- Ensure icon works at small sizes
- Use bright, eye-catching colors
- Make it unique and memorable
- Test on both light and dark backgrounds

**Don'ts:**
- Don't use text (unless brand name)
- Don't use photos
- Don't include rounded corners (system adds them)
- Don't use gradients that don't scale well
- Don't copy other app icons

### Suggested Icon Concept

For Meme Generator:
- Primary element: Laughing emoji or  speech bubble
- Secondary element: Sparkles or editing pencil
- Color scheme: Vibrant gradient (pink/purple or orange/red)
- Style: Modern, flat design with slight 3D effect

## Screenshots

### Requirements

#### iOS App Store

**iPhone 6.7" (Required)**
- Size: 1290 x 2796 pixels
- Format: PNG or JPEG
- Quantity: 3-10 screenshots

**iPhone 6.5" (Optional but recommended)**
- Size: 1284 x 2778 pixels
- Format: PNG or JPEG

**iPad Pro 12.9" (If supporting iPad)**
- Size: 2048 x 2732 pixels
- Format: PNG or JPEG

#### Google Play Store

**Phone Screenshots**
- Min: 320px
- Max: 3840px
- Recommended: 1080 x 1920 pixels (9:16 ratio)
- Quantity: 2-8 screenshots

**Tablet Screenshots (Optional)**
- Size: 1920 x 1080 pixels or higher
- Quantity: Up to 8

**Feature Graphic (Required)**
- Size: 1024 x 500 pixels
- Format: PNG or JPEG
- No transparency

### Screenshot Content Suggestions

#### Screenshot 1: Home/Templates
- Show the template selection screen
- Highlight variety of meme templates
- Caption: "Choose from 20+ Popular Meme Templates"

#### Screenshot 2: Editor
- Show the meme editor with text being added
- Demonstrate ease of use
- Caption: "Easy Text Editing with Customization"

#### Screenshot 3: Features
- Showcase special features (voice-to-text, OCR, etc.)
- Caption: "Voice Commands & Text Recognition"

#### Screenshot 4: Gallery
- Display saved memes
- Caption: "Save & Share Your Creations"

#### Screenshot 5: Premium (Optional)
- Show premium features
- Caption: "Unlock Premium for Unlimited Memes"

### Screenshot Design Tips

**Best Practices:**
- Use device frames for professional look
- Add descriptive text overlays
- Show the app in use (not just static screens)
- Use consistent branding/colors
- Highlight key features
- Show happy/engaging content

**Tools:**
- [Figma](https://www.figma.com/) - Design tool
- [Canva](https://www.canva.com/) - Easy templates
- [Screely](https://www.screely.com/) - Add device frames
- [AppLaunchpad](https://theapplaunchpad.com/) - Screenshot generator

### Video Preview (Optional)

**iOS App Preview:**
- Length: 15-30 seconds
- Size: 1920 x 1080 pixels (landscape) or 1080 x 1920 (portrait)
- Format: .mov, .mp4, or .m4v
- Shows: Key features, user flow, value proposition

**Android Promo Video:**
- Length: Up to 2 minutes (30 seconds recommended)
- Upload to YouTube
- Link in Play Store listing

### App Store Privacy Details

#### iOS App Privacy

**Data Collected:**
- Identifiers: Device ID (for analytics)
- Usage Data: App interactions (anonymous)
- Diagnostics: Crash reports

**Data Not Linked to User:**
- All collected data is anonymous
- No personal information collected

**Third-Party SDKs:**
- Google AdMob (advertising)
- Firebase Analytics (analytics)
- Sentry (crash reporting)

#### Google Play Data Safety

**Data Shared:**
- Device identifiers (for ads)
- App activity (for analytics)

**Data Security:**
- Data encrypted in transit
- No data collection without user control
- Can request data deletion

## Submission Checklist

### Pre-Submission

#### Technical Requirements
- [ ] App builds without errors
- [ ] All features tested on physical devices
- [ ] No crashes or critical bugs
- [ ] Performance is acceptable (smooth scrolling, fast load times)
- [ ] Memory leaks checked and fixed
- [ ] Works on minimum OS version specified

#### Assets
- [ ] App icon (all required sizes)
- [ ] Screenshots (at least 3, up to 10)
- [ ] Feature graphic (Android)
- [ ] Promo video (optional)
- [ ] App preview video (iOS, optional)

#### Store Listing
- [ ] App name
- [ ] Subtitle/short description
- [ ] Full description
- [ ] Keywords/search terms
- [ ] Category selected
- [ ] Content rating completed
- [ ] Privacy policy URL
- [ ] Terms of service URL
- [ ] Support email
- [ ] Website URL (optional)

#### Legal & Compliance
- [ ] Privacy policy reviewed
- [ ] Terms of service reviewed
- [ ] Age rating appropriate
- [ ] Content rating questionnaire completed
- [ ] Export compliance (iOS)
- [ ] COPPA compliance verified

### iOS App Store Submission

**Required:**
1. App Store Connect account
2. Developer Program membership ($99/year)
3. TestFlight testing (recommended)
4. App-specific password for uploading

**Steps:**
1. Create app listing in App Store Connect
2. Upload build via Xcode or Transporter
3. Submit for review
4. Respond to any feedback
5. Release (manual or automatic)

**Review Time:** 1-3 days typically

### Google Play Store Submission

**Required:**
1. Google Play Console account
2. Developer registration ($25 one-time)
3. Internal testing track (recommended)
4. Release signing key

**Steps:**
1. Create app listing in Play Console
2. Upload AAB file
3. Complete store listing
4. Submit for review
5. Release to production

**Review Time:** Few hours to 1-2 days
